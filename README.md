# Colour Match Networking

A browser game for London ACM SIGGRAPH's women's speed networking event.

Each round, slot-machine reels pair up the five sticker colours (magenta, green, red, yellow, orange) into three pairs: two mixed pairs and one colour that pairs with itself. Attendees get 30 seconds to find their match, then a 3-minute talk timer runs with two icebreaker questions on screen. Eight rounds fill a 30-minute session, and rounds 1–5 go through all 15 possible colour combinations.

## Running it

Open `index.html` in a browser (best in Safari or Chrome on a Mac for Helvetica Neue). No install or internet connection is needed. Keep the images in the same folder as `index.html`.

If GitHub Pages is turned on for this repository, the game also runs at the Pages address.

## Controls

| Key | Action |
| --- | --- |
| Space or Enter | Spin / next round |
| P | Pause or resume the timer |
| N | Skip to the next stage |
| F | Full screen |

The buttons in the bottom-right corner do the same, and also open the settings for questions, number of rounds and timings. Settings are saved in the browser used to present.
